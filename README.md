# UH-Programming-Data-Structures

This repository provides C++ examples and mock exam solutions for common data structures taught at the University of Houston and similar courses. It is designed to help students practice and understand key concepts through runnable programs and guided code structure.

---

## Structure

Each subfolder contains one or more of the following:
- Source files (`.cpp`, `.h`)
- A `build.sh` script for compiling and running the program
- Optional notes or comments for study

Examples include:
- Arrays and Matrices
- Linked Lists (Singly, Doubly, Circular)
- Stacks and Queues
- Trees and Graphs
- Sorting and Searching
- Exam mock problems

---

## How to Run a Program

1. Navigate to the folder of the program you'd like to run. For example:

  ```bash
  cd Exam\ 1/Matrix
  ```

2. Make the `build.sh` scrpt executable:

  ```bash
  chmod +x build.sh
  ```

3. Run the program:

  ```bash
  ./build.sh
  ```
